📚 Sistem Manajemen Perpustakaan (Library Management System)

Sistem Informasi Perpustakaan sederhana yang dirancang untuk mempermudah pengelolaan data buku, anggota, serta transaksi peminjaman dan pengembalian buku secara efisien.

🎯 Tujuan Proyek

Proyek ini dibuat untuk memodernisasi dan menyederhanakan proses administrasi perpustakaan yang sebelumnya manual menjadi tersentralisasi dan terdigitalisasi, sehingga meminimalkan risiko kesalahan pencatatan data.

✨ Fitur Utama

📖 Manajemen Data Buku (CRUD):

Menambahkan koleksi buku baru.

Mengubah dan memperbarui informasi buku.

Menghapus data buku yang sudah tidak tersedia.

Mencari buku berdasarkan judul atau kategori.

👥 Manajemen Anggota:

Pendaftaran anggota/pemijam baru.

Pengelolaan profil dan status keanggotaan.

🔄 Transaksi Peminjaman & Pengembalian:

Pencatatan proses peminjaman buku oleh anggota.

Proses pengembalian buku beserta kalkulasi otomatis tanggal jatuh tempo.

Pembatasan jumlah maksimal buku yang dipinjam.

📊 Laporan & Monitoring:

Ringkasan ketersediaan stok buku secara real-time.

Riwayat transaksi peminjaman anggota.

🛠️ Teknologi yang Digunakan

(Silakan sesuaikan teknologi di bawah ini dengan bahasa/framework yang Anda pakai)

Programming Language: JavaScript / PHP

Database: MySQL 

Tools & Version Control: Git & GitHub

💡 Konsep Layanan & Cara Kerja

Petugas Perpustakaan menginputkan data buku dan mendaftarkan anggota ke dalam sistem.

Anggota memilih buku yang ingin dipinjam.

Sistem mencatat transaksi, memperbarui stok buku yang tersedia, dan menentukan tanggal batas pengembalian.

Saat pengembalian, sistem mengubah status pinjaman dan mengembalikan stok buku secara otomatis.
